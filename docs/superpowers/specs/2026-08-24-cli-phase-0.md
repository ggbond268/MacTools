# CLI Phase 0 transport contract

## Decision

MacTools will validate the local command-line transport in a narrow prototype before exposing actions. The `mactools` executable remains a separately downloadable product. The app embeds only an opt-in per-user LaunchAgent broker so the separately installed CLI can connect to the host.

## Components

- `MacToolsCLIProtocol` is an independent static module containing versioned wire models, strict JSON coding, semantic validation, size limits, and XPC interfaces. It does not depend on the app or PluginKit.
- `MacToolsCLIBroker` is registered only after the user enables Command Line in Settings. It authenticates the exact same-user, same-Team-ID host and CLI signing roles, owns cold launch, negotiates the three protocol ranges, bounds concurrent requests, and forwards opaque envelopes.
- `MacTools` registers its host endpoint after startup is ready and serves only the `doctor` operation.
- `MacToolsCLI` provides stable human and JSON output, bounded monotonic waits, cancellation forwarding, and deterministic exit codes.

Product version and build strings are diagnostics only. Admission and compatibility depend on the authenticated role and overlapping protocol ranges, so a separately released CLI can interoperate with compatible app versions.

## Phase 0 surface

- `help`
- `version [--json]`
- `doctor [--json]`

The app does not embed or install the CLI. Action discovery/execution, workflows, plugin operations, parameter schemas, PluginKit changes, updater integration, notarized CLI archives, Homebrew packaging, and release manifests belong to later phases.

## Safety contract

- The LaunchAgent is opt-in and per user.
- The listener and every method enforce the caller's exact signing role; same Team ID alone is insufficient.
- The broker derives and validates its containing app before cold launch, does not activate its UI, and suppresses launch storms.
- JSON rejects oversized data, unknown top-level fields, duplicate fields at every nesting level, missing fractional timestamps, and invalid outcome/payload/rejection combinations.
- Each client may have at most 8 requests in flight, with 32 globally, and request IDs are unique across clients.
- `version` never requests host launch. `doctor` has bounded startup and response deadlines and forwards cancellation.

## Review gate

The PR stays draft until focused tests and repository CI pass and signed end-to-end evidence is recorded for macOS 14, macOS 15, and the current macOS release. Phase 1 should begin in a later PR only after this contract is accepted.
